# [Mental Addition Trainer](https://mental-addition-trainer.vercel.app/)

A mental addition trainer website for mental calculators who want to build
speed and stamina in multi-row addition.

## Features

- Customizable sets: 1–10 digits per number, 2–10 rows per question, and any number of questions
- Live timer with millisecond precision
- Per-question timing and end-of-set statistics
- Save your results as a screenshot to share or track progress
- Responsive layout that works on desktop and mobile

## How to use

1. Pick the number of digits, rows, and questions.
2. Click **New set**.
3. Add up the numbers shown and type your answer.
4. When the set ends, review your time and stats, then restart or change options.

## Run locally

    git clone https://github.com/WalidKsentini/Mental-Addition-Trainer.git
    cd Mental-Addition-Trainer
    # open index.html in your browser

No build step or dependencies are needed.

## Built with

HTML, CSS, and vanilla JavaScript. Screenshots use html2canvas.
